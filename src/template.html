Loot rarity

Change how often Nightreign drops Common, Uncommon, Rare and Legendary loot. Works with modded regulation files, so modded weapons are included.

Open a regulation.bin

Pick the regulation.bin your game currently uses. Unmodded, it's in ELDEN RING NIGHTREIGN\Game. If you use a mod that has its own regulation.bin, pick the mod's copy. The file is read on this computer only.

Or drag the file onto this box. Always start from the original file, not one this editor built.

Weapon drop odds

Average chance of each rarity when a weapon drops, across every enemy, boss and world loot table.

OriginalWith your changes
This regulation.bin was made by this editor. Changes you make now are applied on top of the earlier ones. To start clean, open the original regulation.bin from your game or mod instead.

Install with ME3

  1. Save the file as regulation.bin in a folder named loot-rarity next to your .me3 profile.
  2. Launch with the profile that loads loot-rarity after your other mods. One is included with this editor.

Settings

Your numbers are kept in this browser. Save them to a file to reuse them after a game or mod update.
